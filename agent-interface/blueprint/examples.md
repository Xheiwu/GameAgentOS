# Blueprint Example

## User Request

Create a mobile Chinese fantasy action roguelike.

## Module Composition

```
Roguelike Core
+
Action Combat
+
Boss Pattern
+
Reward System
+
Progression System
```

## Generated Core Loop

```
Enter dungeon
↓
Combat
↓
Collect rewards
↓
Build character
↓
Challenge stronger encounters
↓
Repeat
```

## MVP Rule

Only implement the minimum loop required to prove fun.
