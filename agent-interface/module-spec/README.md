# Agent Module Specification Standard (F2)

## Purpose

Define the standard format for every GameAgentOS module.

A module is not a document. It is an executable knowledge package for AI agents.

## Required Sections

1. Identity
2. Intent
3. When To Use
4. Player Experience Goal
5. Required Systems
6. Components
7. Events
8. Parameters
9. Rules
10. Dependencies
11. Compatibility
12. Examples
13. Anti-patterns
14. Validation
15. Engine Mapping

## Principle

Modules describe reusable game design capabilities, not copied games.
