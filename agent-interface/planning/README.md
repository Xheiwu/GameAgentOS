# Game Design Planning Agent

## Purpose

Convert retrieved Agent Modules into a complete game design plan.

Retrieval finds capabilities. Planning decides how capabilities form a game.

## Flow

```
User Intent
    ↓
Query Understanding
    ↓
Module Retrieval
    ↓
Game Design Planning
    ↓
Implementation Plan
```

## Responsibilities

The Planning Agent determines:

- Core gameplay loop
- Player progression
- System dependencies
- Module order
- MVP scope
- Technical implementation priority
