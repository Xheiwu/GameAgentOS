# Agent Module Layer

## Purpose

Executable knowledge packages designed for AI agents.

Agents should consume this layer instead of raw research.

A module contains:

- Intent
- Requirements
- Inputs
- Outputs
- Components
- Events
- Rules
- Parameters
- Validation
- Engine mapping

Example:

```
User request
 ↓
Retrieve Agent Module
 ↓
Generate Unity/Godot/UrhoX/Web implementation
```
