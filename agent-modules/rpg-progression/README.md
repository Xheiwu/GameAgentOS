# RPG Progression Core

Version: 1.0

## Purpose

A reusable RPG progression capability package for AI agents.

It defines how characters grow through levels, attributes, equipment, skills, quests and economy.

## Position

```
Combat Core
      +
Roguelike Core
      +
RPG Progression Core
      ↓
Complete RPG Experience
```

## Modules

- Character Level
- Attribute System
- Equipment System
- Affix System
- Skill Tree
- Quest System
- Economy System

## Agent Usage

Use this module when the user requests:

- RPG
- ARPG
- MMORPG
- Equipment progression
- Character growth
- Long term retention systems
