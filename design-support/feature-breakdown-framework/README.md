# H1.3.4 Feature Breakdown Framework

## Purpose

帮助 Agent 将一个游戏想法从体验层逐步拆解到系统层和内容层。

它不是任务生成器，也不是固定策划模板。

它提供分析路径，让 Agent 避免从功能列表开始设计。

## Breakdown Flow

Game Idea

↓

Player Experience

↓

Player Actions

↓

Core Loop

↓

Required Systems

↓

Content Categories

↓

Implementation Scope

## Example

Idea:

做一个观鸟收集游戏

Experience:

探索、发现、收集

Actions:

寻找、观察、记录

Systems:

探索地图、观察机制、图鉴、事件

Content:

鸟类、环境、声音、季节

## Principle

先理解玩家体验，再推导系统。

不要从功能堆叠反推游戏。
