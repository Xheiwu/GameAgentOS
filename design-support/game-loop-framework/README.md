# Game Loop Framework

## Purpose

Provide Agent with a thinking framework for analyzing and designing gameplay loops.

This is not a fixed template and does not prescribe implementation.

## Questions

1. What action does the player repeatedly perform?
2. What immediate feedback does the player receive?
3. What decision or change happens after the action?
4. What creates the motivation for the next cycle?

## Generic Structure

Player Action

↓

Feedback

↓

Decision / Reward

↓

Growth or Change

↓

New Challenge

## Usage

Agents should adapt this framework according to genre, platform and target experience.
