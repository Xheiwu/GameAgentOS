# Architecture Refactor v2.0

## Goal

GameAgentOS is not a game design template library.

It is an AI game development operating system that provides:

- development standards
- design reasoning frameworks
- reusable capability modules
- execution structures

The goal is to help AI agents create more complete, mature, and commercial-quality games.

## Core Principle

Do not replace Agent creativity.

Provide:

- context
- frameworks
- patterns
- modules

Allow Agent to decide the final implementation.

## New Architecture

```
GameAgentOS

0. Development Standard
   - Commercial game principles
   - Production workflow
   - Scope control

1. Game Understanding
   - Query understanding
   - Reference analysis
   - Market/platform context

2. Design Intelligence
   - Patterns
   - Player experience
   - Design principles

3. Game Architecture
   - Game loop
   - System relationships
   - Progression architecture

4. Capability Modules
   - Combat
   - Roguelike
   - Card
   - RPG
   - Economy

5. Commercial Completeness
   - Retention
   - Monetization
   - Content pipeline
   - Live operation

6. Agent Execution
   - Blueprint
   - Task generation
   - Coding
```

## Layer Responsibilities

### Pattern Layer

Answers:

"Why does this design work?"

Not:

"How must the game be implemented?"

### Module Layer

Answers:

"What reusable capability can be implemented?"

### Blueprint Layer

Answers:

"How should this specific game be assembled?"

## Design Direction

GameAgentOS should enhance Agent reasoning instead of constraining it.
