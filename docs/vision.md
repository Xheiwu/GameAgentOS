# GameAgentOS Vision

## Goal

Build a structured knowledge system for AI game development.

The system converts game design experience into reusable modules that AI agents can understand.

## Core Workflow

1. Analyze excellent games
2. Extract design patterns
3. Convert patterns into standard modules
4. Let AI agents reuse modules
5. Generate implementations for different engines

## Long Term Goal

Create a common language between game designers and AI agents.

A game mechanic should be described once and implemented anywhere.

Supported targets may include:

- Unity
- Godot
- Web
- UrhoX
- Other engines
