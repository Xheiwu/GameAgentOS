# Genre Classification Foundation

## Purpose

Convert a user's game idea into structured genre and gameplay pattern information.

## Principle

Genre is not only a label. Agent should identify:

- core gameplay loop
- player interaction style
- progression model
- content structure
- required modules

## Example

"Hades-like Chinese monster action game"

Should become:

- Action Combat
- Roguelike Run Loop
- Build Variation
- Boss Challenge
- RPG Progression
