# H1.0.4 Module Selection Foundation

## Purpose
Convert analyzed player requirements into a set of GameAgentOS modules.

## Flow
User Intent
→ Query Understanding
→ Genre Classification
→ Reference Analysis
→ Module Selection
→ Blueprint Composition

## Principles
- Select capabilities, not copied games.
- Prefer minimal sufficient modules.
- Respect dependency relationships.
- Support hybrid genres.

## Example
Input:
"Hades style Chinese monster action roguelike"

Selected:
- Combat Core
- Roguelike Core
- RPG Progression
- Boss Pattern
