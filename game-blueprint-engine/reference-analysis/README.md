# Reference Analysis Foundation

## Purpose

Convert reference games into reusable design patterns instead of copying titles.

## Flow

Reference Game

↓

Core Experience Extraction

↓

Design Pattern Extraction

↓

System Module Mapping

## Example

Input:

"Make a game like Monster Hunter"

Output:

Extract:

- Boss hunting loop
- Preparation phase
- Weakness discovery
- Material rewards
- Equipment progression

Map:

- Combat Core
- Boss Pattern
- RPG Progression
- Equipment System
