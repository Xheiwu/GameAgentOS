# GameAgentOS Capability Index v0.1

This file helps agents discover available game development capabilities.

## Combat Domain

Use when:
- real-time combat exists
- player controls attacks, movement, skills
- enemies and bosses need behavior design

Provides:
- player control
- combat loop
- damage pipeline
- status effects
- skills
- enemy behavior
- boss behavior
- combat feedback

Related:
Roguelike, RPG

---

## Roguelike Domain

Use when:
- replayability is important
- runs contain variation
- players create builds during play

Provides:
- run structure
- randomization
- choices
- build formation
- rewards
- difficulty scaling
- meta progression
- replayability

Related:
Combat, RPG

---

## RPG Domain

Use when:
- characters grow over time
- equipment, attributes or collection exist
- long-term progression is required

Provides:
- character growth
- attributes
- equipment
- inventory
- affixes
- skill growth
- collection
- quests

Related:
Combat, Roguelike
