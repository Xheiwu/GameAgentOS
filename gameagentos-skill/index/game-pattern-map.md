# Game Pattern Map v0.1

Patterns are references for capability selection, not templates.

## Action Roguelike

Core capabilities:
- Combat
- Roguelike

Optional:
- RPG

Focus:
- responsive controls
- combat feedback
- build choices
- replay loop

---

## Spell Construction Roguelike

Core capabilities:
- Combat
- Roguelike

Focus:
- ability combination
- experimentation
- discovery

---

## Loot ARPG

Core capabilities:
- Combat
- RPG

Focus:
- combat loop
- rewards
- equipment
- affixes
- progression

---

## Idle RPG

Core capabilities:
- RPG

Focus:
- growth
- collection
- progression
- retention

Agents should select patterns based on player experience, not copy examples.
