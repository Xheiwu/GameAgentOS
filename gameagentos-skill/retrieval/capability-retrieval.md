# Capability Retrieval Rules v0.1

When receiving a game request:

1. Understand player intent.
2. Identify desired experience.
3. Select architecture needs.
4. Retrieve matching capabilities.
5. Use references only as inspiration.

Priority:

Player Experience
>
Core Loop
>
Architecture
>
Capability
>
Reference

Do not load every capability. Retrieve only what supports the current design problem.
