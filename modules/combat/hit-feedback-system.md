# Hit Feedback System

## Overview

A reusable combat feedback module that describes how player actions create satisfying impact.

## Goal

Create a clear emotional response:

- Power
- Impact
- Control
- Confirmation

## Universal Feedback Layers

1. Visual feedback
2. Animation feedback
3. Time feedback
4. Camera feedback
5. Audio feedback
6. Numeric feedback

## Supported Game Types

- 2D Action
- 3D Action
- Turn Based RPG
- Card Games
- Strategy Games

## Future Analysis

Reference games should be analyzed and converted into parameters instead of copied directly.
