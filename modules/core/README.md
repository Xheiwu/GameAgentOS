# Core Game Agent Modules

Core modules are the foundation layer of GameAgentOS.

They describe universal game capabilities that are shared across different genres.

Current modules:

- Event Trigger System
- State Change System
- Action Impact Response

These modules are not complete gameplay features.
They are reusable capabilities that AI agents combine to create larger systems.

Example:

Boss Battle =

Event System
+
State System
+
AI Behavior
+
Action Impact Response
+
Reward System
