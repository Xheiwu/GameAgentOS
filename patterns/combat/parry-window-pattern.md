# Parry Window Pattern

## Intent

Convert defensive actions into high-skill reward moments.

## Core Model

```
Enemy Intent
 ↓
Attack Telegraph
 ↓
Reaction Window
 ↓
Success Or Failure
 ↓
State Change
```

## Agent Rules

A parry system should define:

- attack timeline
- valid timing window
- success reward
- failure consequence

## Avoid

Defense that only reduces damage without creating meaningful decisions.
