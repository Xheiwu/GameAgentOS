# Null Sovereign Gameplay Analysis

## Core Experience

A skill-based boss duel focused on reading attacks, parrying, breaking posture and executing vulnerable enemies.

## Experience Loop

```
Observe
 ↓
Predict
 ↓
React
 ↓
Create Advantage
 ↓
Execute
 ↓
Reward Feedback
```

## Main Design Questions

- How does the player understand enemy intent?
- How does defense become an offensive opportunity?
- How does the game create a high-value reward moment?

## Extracted Concepts

- Telegraphed attacks
- Timing-based defense
- Secondary combat resource
- Vulnerability window
- Escalating feedback intensity
